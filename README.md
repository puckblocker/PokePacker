# PokePacker
This is an e-commerce website for a selling / buying pokemon cards

**Sprint 1:**\
The Work: \
During Sprint 1, the entire group was present for each meeting. We worked on completing the User Stories first, using the examples from lab. After we finished the User Stories, each member was assigned a part of the SRS document to fill out. Each member completed their task in a timely manner.

The Information:\
The User Stories Doc contains information that describes different events or scenarios that a user may go through during their use of our website. Each user stories was used later to form our Functional Requirements. The User Stories also gave us many ideas of what needs to be implemented. From the User Stories, we were able to start formatting the SRS Doc. The SRS Doc contains information regarding the website and how it will be structured, formatted, and built.
