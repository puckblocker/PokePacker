# PokePacker
PokePacker is an e-commerce website designed for the purchasing and selling of Pokemon TCG cards. The site will be able to support a growing audience of differing users (buyers, sellers, admins, and visitors).

**Sprint 1:**\
The Work: \
During Sprint 1, the entire group was present for each meeting. We worked on completing the User Stories first, using the examples from lab. After we finished the User Stories, each member was assigned a part of the SRS document to fill out. Each member completed their task in a timely manner.

The Information:\
The User Stories Doc contains information that describes different events or scenarios that a user may go through during their use of our website. Each user stories was used later to form our Functional Requirements. The User Stories also gave us many ideas of what needs to be implemented. From the User Stories, we were able to start formatting the SRS Doc. The SRS Doc contains information regarding the website and how it will be structured, formatted, and built. 

**Sprint 2:**\
The Work: \
For Sprint 2, each member was present for our meetings. We worked mainly on creating our diagrams and getting the GitHub issues filled out. After diagrams were initially looked at by Tirian, we made adjustments based on his feedback and made the final submisson.

The Information:\
The diagrams contain information that illustrate our user stories. There are activity diagrams, state diagrams, sequence diagrams, component diagrams, an architecture diagram, and use case diagrams. The user stories were also used to create our GitHub issues. The GitHub issues set up a list of task that we need to finish as we continue to work on the project.
